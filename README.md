# Confluencia Series

React app to search TV shows using the public TVMaze API, view details and save favorites.

## Libraries
- React + Vite
- react-router-dom
- TVMaze API

## Requirements covered
State (useState), Context (favorites), react-router with search params (/?q=), controlled form, custom hooks (useSeries, useFavoritos), components, responsive design (320px to 2000px).

## Difficulties
Very little time to finish; I learned React Router, Context and custom hooks while building the project with AI assistance.
